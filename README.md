# Ognjen Rajković — Portfolio

Next.js (App Router) · Tailwind CSS v4 · Framer Motion · TypeScript

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
```

- All content (projects, skills, contact, process) lives in `lib/data.ts`.
- Palette is defined as theme tokens in `app/globals.css`. The second "muted-teal" scale from the brief is named `moss`.
- Project screenshots are in `assets/`.
